# RZD Synthetic Data Prompt v1.3 — Visualization, Monte-Carlo & ML-Ready Export

> **v1.3** — Добавлена визуализация, Monte-Carlo режим и экспорт, готовый для ML.

## 🚀 Ключевые улучшения v1.3

- **Визуализация**:
  - Interactive timeline событий
  - Простая карта / схема маршрутов (Canvas)
  - Визуальное отображение нарушений и их влияния

- **Monte-Carlo режим**:
  - Запуск многих симуляций с разными seed
  - Сбор статистики по задержкам и нарушениям
  - Вероятностные распределения и confidence intervals

- **ML-Ready Export**:
  - Структурированные данные для обучения моделей предсказания задержек
  - Фичеры: тип поезда, участок, время суток, погодные условия, наличие нарушений на предыдущих участках и т.д.
  - Target: задержка / вероятность задержки

- Улучшенный буилдер сценариев с превью влияния

## 📄 Промпт v1.3

```markdown
Создай современное веб-приложение на Rust + WebAssembly для генерации синтетических данных РЖД с Discrete Event Simulation, продвинутой моделью нарушений и визуализацией.

**Tech Stack:** Rust + wasm-bindgen + rand + rand_distr + chrono + fake (RU) + serde + web-sys (Canvas)

**Режимы:**
- Static Generation
- Discrete Event Simulation (DES)
- Monte-Carlo Simulation (multiple runs + statistics)

- Monte-Carlo режим:
  - Запуск N симуляций
  - Сбор статистики (средние, медиана, персентили, confidence intervals)

- ML-Ready Export:
  - Экспорт в формате, удобном для обучения моделей предсказания задержек
```
