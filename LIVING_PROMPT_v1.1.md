# RZD Synthetic Data Prompt v1.1 (с Discrete Event Simulation)

> **Улучшенная версия** — теперь с поддержкой **дискретно-событийного моделирования (DES)** для генерации реалистичных поездок, маршрутов и нарушений.

## 🚀 Основные улучшения v1.1

- Два режима работы: **Static Generation** + **Discrete Event Simulation**
- Простая модель железнодорожной сети (станции + участки)
- Моделирование поездов в движении
- Реалистичная модель **нарушений** с каскадным эффектом
- Генерация **Event Log** (журнал событий с таймстемпами)
- Вывод статистики по задержкам и нарушениям

## 📄 Промпт v1.1 (копируй в Cursor / Claude)

```markdown
Создай современное веб-приложение на Rust + WebAssembly для генерации синтетических данных РЖД с поддержкой Discrete Event Simulation.

**Tech Stack:**
- Rust + wasm-bindgen + rand + rand_distr + chrono + fake (RU) + serde + serde_json
- Frontend: Tailwind CSS + vanilla JS + Chart.js
- Приоритетная очередь событий (BinaryHeap)

**Два режима работы:**

1. **Static Generation** (как в v1.0) — быстрая генерация статических данных
2. **Discrete Event Simulation** — полноценная симуляция движения поездов и нарушений

**Функционал для DES режима:**

- Простая модель сети: список станций + участки с временем в пути
- Параметры симуляции:
  - Длительность симуляции (часы)
  - Количество поездов / час
  - Интенсивность нарушений (0–100%)
  - Seed

- Модель нарушений:
  - Вероятность возникновения на участке
  - Распределение длительности нарушения
  - Влияние на скорость поездов и каскадный эффект

- Выход:
  - Event Log (таймстемп, тип события, поезд, станция, детали)
  - Синтетические данные поездок и задержек
  - Статистика: средняя задержка, кол-во нарушений, загрузка участков

**UI:**
- Вкладки: Static / Simulation
- Настройки симуляции в боковой панели
- Timeline событий + простая визуализация маршрутов
- Экспорт Event Log в CSV/JSON

Сделай красивый, современный интерфейс на русском языке. Код должен быть чистым и хорошо комментированным.

Создай полный Cargo проект с инструкцией по сборке.
```
