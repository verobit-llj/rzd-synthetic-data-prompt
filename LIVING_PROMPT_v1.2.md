# RZD Synthetic Data Prompt v1.2 — Advanced Disruption Modeling & Scenarios

> **v1.2** — Добавлена детальная модель нарушений с разными типами и системой сценариев.

## 🚀 Ключевые улучшения v1.2

- **Разные типы нарушений**:
  - Technical (отказ оборудования, сигнальная система)
  - Weather (снег, гроза, жара, туман)
  - Organizational (кадровые, планирование, координация)
  - Infrastructure (ремонт пути, ограничение пропускной способности)

- **Система сценариев**:
  - Predefined сценарии («Тяжёлый снег на Восточном полигоне», «Крупный ремонт на главном ходу»)
  - Custom сценарии (выбор типов нарушений + интенсивность + зоны влияния)
  - Каскадные эффекты между участками

- **Улучшенная модель влияния**:
  - Разные типы нарушений влияют на скорость, пропускную способность и вероятность отмены по-разному
  - Возможность задавать сценарии с глобальным влиянием («плохая погода на всём направлении»)

- **Event Log** с более богатыми деталями (тип нарушения, северитость, влияние на конкретные поезда)
