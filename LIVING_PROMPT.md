# RZD Synthetic Data Prompt (Living Document)

> **Лучший промпт и принципы для генерации реалистичных синтетических данных РЖД** с помощью Rust + WebAssembly.

Этот репозиторий — живой документ. Мы постоянно улучшаем промпт, чтобы получать максимально реалистичные данные для задач машинного обучения, тестирования и аналитики в сфере железнодорожного транспорта.

## 🚀 Текущая лучшая версия (v1.0)

### Копируй этот промпт в Cursor / Claude / Lovable:

```markdown
Создай современное веб-приложение на Rust + WebAssembly (wasm-bindgen) для генерации синтетических данных РЖД.

Техстек: Rust + wasm-bindgen + rand + rand_distr + chrono + fake (RU locale) + serde + serde_json.
Frontend: Tailwind CSS (CDN) + vanilla JS + Chart.js.

Приложение должно работать полностью в браузере.

Функционал:
- Боковая панель настроек с выбором типа данных (Расписание, Билеты, Грузы, Задержки, Продажи)
- Слайдер количества записей (100–50 000)
- Диапазон дат + Seed + Уровень реализма (1–10)
- Дополнительные фильтры по типам поездов и популярным маршрутам
- Главная таблица предпросмотра + статистика + 2–3 графика
- Экспорт в CSV, JSON, Parquet

Реализм: реальные станции, логическое время в пути, правильные распределения задержек, связанные данные.

Сделай красивый тёмно-синий интерфейс в стиле транспортных приложений на русском языке.

Создай полный проект с Cargo.toml, src/lib.rs, index.html и README с инструкцией по сборке (wasm-pack build --target web).
```

## 📊 Принципы качественных синтетических данных для РЖД

- **Реалистичные распределения**: задержки — экспоненциальное, пассажиропоток — нормальное / Пуассоновское
- **Логическая связность**: время в пути соответствует расстоянию между станциями
- **Реалистичные сущности**: номера поездов (001А, Сапсан), коды станций, русские ФИО, типы грузов
- **Воспроизводимость**: обязательный seed + детерминированная генерация
- **Связанные таблицы**: билет → поезд + дата + станция посадки/высадки
